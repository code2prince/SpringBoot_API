# SpringBoot_API
Java Spring Boot Crud


A robust and scalable RESTful CRUD (Create, Read, Update, Delete) API built using Java and the Spring Boot framework. This project serves as a foundational blueprint for managing resources efficiently with a clean architectural design.

## Features

* **Full CRUD Operations:** Seamlessly handle data creation, retrieval, updates, and deletion.
* **Layered Architecture:** Clear separation of concerns using the Controller-Service-Repository pattern.
* **Data Persistence:** Integrated with Spring Data JPA for object-relational mapping.
* **Input Validation:** Robust request body validation using Hibernate Validator.
* **Exception Handling:** Centralized global exception handling returning clean error responses.
* **API Documentation:** Built-in Swagger/OpenAPI integration for easy API testing.

---

## 🛠️ Tech Stack

* **Backend:** Java 21+ / Spring Boot 3.x
* **Database:** MSSQL
* **ORM Framework:** Spring Data JPA (Hibernate)
* **Build Tool:** Maven 
* **Testing:** JUnit 5, Mockito

---

## 📋 Prerequisites

Before running this project, ensure you have the following installed:
* [Java Development Kit (JDK 21 or higher)](https://adoptium.net/)
* [Apache Maven](https://maven.apache.org/)
* An IDE (IntelliJ IDEA, Eclipse, or VS Code)
* [Postman](https://www.postman.com/) or curl (for testing endpoints)
